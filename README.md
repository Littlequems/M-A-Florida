# M&A Florida

Demonstração pública sanitizada desenvolvida para o portfólio da **CarolTech**.

## Visão geral
Pipeline de prospecção e pré-análise que transforma oportunidades dispersas em uma base comparável com preço, retorno, payback, risco, distância e score.

## Capacidades
- Coleta estruturada de oportunidades
- Normalização de dados
- Cálculo de distância
- Payback e retorno
- Score de atratividade
- Exportação para Excel

## Privacidade
Este repositório público **não contém dados reais de clientes ou operações**. Empresas, preços, cidades operacionais, contatos e indicadores exibidos são fictícios.
